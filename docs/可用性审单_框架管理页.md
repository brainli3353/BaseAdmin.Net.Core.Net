﻿﻿# 可用性审单 — 框架管理页（批 UX·2026-10-25）

> 用途：22 个管理页逐页过审的统一口径；审计臂**只读评**，修复批按同清单逐项落。
> 分级：**P0**＝误导/丢失操作结果类（无确认即删、筛选后不回第一页、错误被吞）；**P1**＝明显低效（缺关键字/状态筛选、长文本无溢出处理、无 loading/空态）；**P2**＝锦上添花（列自定义、查询入 URL、快捷键）——**P2 只列不修**（候用户）。
> 边界：只评**前端页面层**；后端 Input 不支持的筛选=记"需后端件"单列，不在本页批解决。
> **本审单＝框架级页面标准（非一次性审计）**：本仓 22 页修完后，审单升格为**新增管理页的验收单**——新页面按约定 14 立项时 A/B/C 全项为默认要求（P0/P1 必做、P2 按需），评审按本单逐项打勾；"能跑但粗糙"不算完成。配套机制（批 UX 交付物）：从最佳页抽**页型模板**（列表页/左右树表页/日志查询页三型）落 `templates/`，fork 继承、新页从模板起，不从零手搓。

## A 筛选区
- A1 关键字搜索框（姓名/编码/名称类模糊字段；后端 Input 已有对应参数？）
- A2 状态/枚举下拉（数据字典或枚举驱动，非硬编码中文）
- A3 时间范围（日志/时间域页面必有；后端参数支持为准）
- A4 重置按钮（清全部筛选并回第一页重查）
- A5 **筛选/搜索后分页回第一页**（P0：筛选停在第 N 页＝结果误导）
- A6 回车触发搜索

## B 表格
- B1 长文本列：show-overflow-tooltip（禁撑破布局）
- B2 时间列格式统一（`YYYY-MM-DD HH:mm:ss`）＋可排序（后端支持时）
- B3 id 列：雪花 19 位**全展示**（G33 后为 string，禁 slice 截断误导）或提供复制
- B4 loading 遮罩（查询期间）
- B5 空态（无数据提示，非空白）
- B6 分页：总条数展示＋page-size 可选（10/20/50）
- B7 操作列右 sticky；按钮 >3 收纳"更多"
- B8 状态列用 tag 色义（启用绿/停用灰/异常红）

## C 操作与反馈
- C1 删除/停用类**二次确认**（P0）
- C2 提交中按钮 loading＋防重复提交
- C3 错误经 `errCode` 透出（不弹"操作失败"吞细节）
- C4 保存/删除成功后列表刷新＋toast
- C5 表单校验（必填/长度）在提交前于前端拦一道

## D 实用性
- D1 后端已有能力的前端入口齐全（导出/详情/刷新缓存等，存在才评）
- D2 高频动作 ≤2 次点击（新建/搜索）
- D3 弹窗宽度与内容匹配（长表单不挤 500px）

## 公共件
- `web/src/utils/format.ts` → `formatDateTime(v?)`：时间列统一 `YYYY-MM-DD HH:mm:ss`，空值 `-`、解析失败原样返回；用法 `formatDateTime(row.createTime)`（B2 全站引用）。
- `web/src/components/BaActionButtons.vue` → 操作列收纳（前 2 项直出、其余折「更多」，`hidden` 不渲染但保留原下标）；用法 `<BaActionButtons :actions="actions" @select="onAction" />`（B7 引用）。
- 两件均零第三方依赖（未引 moment/dayjs），修复批各页引用即生效。
