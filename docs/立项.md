## 一、目标与边界

- **做什么**:一个可复用的基础 Admin 框架(登录鉴权/ORM/实体基类/仓储/RBAC/审计/缓存),原生 ASP.NET Core MVC 实现,不引入 Furion/Admin.NET 全家桶
- **参考**:baseadmin 的**结构**(分层、Business 业务落点)与**核心功能**(SqlSugar ORM、雪花 ID、实体基类、两阶段登录 OTP、软删、分页、多库、CodeFirst 增量)
- **不做什么**:不照搬 Admin.NET 全部功能(工作流/插件/大屏等),只做核心;功能按需逐步补
- **实践**:intel 情报系统是首个落地项目,优先开发其所需基础功能(2026-09-09 冻结:先完成基础框架功能开发,见顶部阶段标注)

## 二、技术栈(对齐 baseadmin 但去 Furion)

| 层 | 选型 | 说明 |
|---|---|---|
| 框架 | **ASP.NET Core MVC**(net10.0) | 原生,无 Furion;控制器+Razor 基础 |
| ORM | **SqlSugarCore** 5.1.4.x | 与 baseadmin 同版本,复用知识 |
| ID | **YitIdHelper 源码移植**(thirdparty/YitIdHelper,2026-08-25 用户拍板不引包,上游 yitter/IdGenerator MIT 许可 9 文件 ~1000 行) |
| 鉴权 | JWT(保留 NuGet JwtBearer,用户拍板)+ Authenticator OTP 两阶段 | **Otp.NET 源码移植**(thirdparty/Otp.NET,2026-08-25 用户拍板不引 NuGet 包,源码 MIT 许可 13 文件 ~1600 行);密码哈希 PBKDF2 原生 |
| 缓存 | Redis(StackExchange.Redis) | 部署内网 Redis |
| 数据库 | PostgreSQL(SqlSugar 驱动) | 多库预留(ConnectionConfigs 模型) |
| 日志 | ILogger + Serilog(可选) | 原生 |
| DI | 原生 IServiceCollection | 替代 Furion 的 App 服务定位 |

## 四、核心功能清单(第一版,按里程碑交付)

### M1 骨架(基础可用)
1. 解决方案 + 四层项目结构 + 构建通过(net10.0)
2. SqlSugar 接入:单库连接(SqlSugarScope 单例注册 ISqlSugarClient)、CodeFirst 自动建表
3. 实体基类:`EntityBaseId`(雪花 long 主键)、`EntityBase`(创建/更新审计字段 + 软删接口 IDeletedFilter)
4. 仓储:`SqlSugarRepository<T>`(SimpleClient 继承 + 分页扩展 `ToPagedListAsync` → PageResult)
5. JWT 登录(账号密码单阶段初验)+ 登录接口 + 鉴权中间件
6. 健康检查、统一响应模型(ApiResult)、全局异常处理中间件

### M2 核心功能
7. **两阶段登录**:密码初验 → Authenticator OTP 校验(Otp.NET),对齐 baseadmin
8. **RBAC 基础**:用户/角色/菜单(实体 + 种子 + 权限校验中间件/过滤器)
9. Redis 缓存接入(登录会话/验证码/通用缓存)
10. 审计:实体审计字段自动填充(过滤器/中间件)+ 操作日志落库
11. 增量种子 `[IncreSeed]` 机制(对齐 baseadmin,避免全量)
12. 多库支持(ConnectionConfigs + ITenant 等价切换)
13. **通用管理前端**(web/):Vue3 + Element Plus + vxe-table 自研面板——两阶段登录流(含 QR 绑定)/后端菜单驱动动态路由/v-perm 按钮权限(与 [MenuPerm] 同源)/SPA 同源自带托管(免 CORS)/双 JWT 刷新闭环/雪花 Id 精度防护

### M3 intel 实践(首个项目)——⏸ 冻结(2026-09-09 裁决,待解冻)
14. **账号管理模块**(Business/Intel 子域):养号账号 CRUD + 代理绑定 + 状态流转
15. 基础 API 组(情报数据查询/看板)
16. 登录对接 intel 实际使用场景

## 五、硬性约定(继承 baseadmin/CLAUDE.md)

1. 业务代码只写 `Business`,框架层(Core/Web.Core/Entry)只做支撑
2. C# 文件编码门（BOM+LF）＝`../MainWorkspace/docs/全局公约.md` §4,4 空格缩进,接口 `I` 前缀,PascalCase（编码/命名从同件 §3/§4）

6. 提交前查敏感文件
