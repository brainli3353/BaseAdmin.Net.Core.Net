## 五、维护约定（防再次膨胀）

1. **新文档归位**：权威活件 → `docs/` 顶层（仅限上表所列族）；移植/评估证据 → `docs/研究/`；历史/被取代 → `docs/archive/`；业务规划 → `docs/业务/规划/`。**禁止**在 `docs/` 顶层新增散件。
2. **一主题一件**：同类只留一份家；被取代的件先归档，不留并列多份。
3. **闭合即归档**（全局公约 §文档卫生②）：待办/里程碑关闭即在活件标 `✅`；历史件批量移入 `docs/archive/<YYYYMMDD>/`。
4. **改结构必同步索引**：动 `docs/` 结构 → 同步改本页分区表＋`框架索引.md §六 文档地图`＋根 `README.md` 文档树（同一提交内）。
5. **引用用全路径**：跨文档引用一律写 `docs/...` 全路径，不写裸文件名（避免搬家即断链）。
6. **编码**：编码门家＝`../MainWorkspace/docs/全局公约.md` §4（门口径＝`repo_check`）。
7. **凭据只写来源不写值**：文档（含 `docs/项目地图_模板.md` 与 fork 后项目地图）只记凭据"在哪个文件/哪个环境变量/哪台机"，**不记凭据值与口令明文**；默认口令一律标注「仅开发默认，生产必改」。
