## 一、项目定位

- **做什么**:自建基础 Admin 框架(原生 ASP.NET Core MVC,零 Furion),参考 baseadmin(Admin.NET.Pro.HHBase)结构与核心功能
- **为什么**:Furion/Admin.NET 全家桶耦合深;用户要轻量可控框架;业务统一落点可长期演进
- **首个实践**:intel 情报系统(账号管理模块最先落地)
- **仓库**:gitea LocalDevelopment/BaseAdminCore(远端 http://192.168.1.202:3000/LocalDevelopment/BaseAdminCore.git,本地 /data/workspace/BaseAdminCore)

## 二、技术栈(定案)

| 层 | 选型 |
|---|---|
| 框架 | ASP.NET Core MVC(net10.0) |
| ORM | SqlSugarCore 5.1.4.x(与 baseadmin 同版) |
| ID | YitIdHelper 源码移植(thirdparty/YitIdHelper,上游 yitter/IdGenerator MIT,不引包) |
| 鉴权 | JWT(保留 NuGet:Microsoft.AspNetCore.Authentication.JwtBearer,2026-08-25 用户拍板)+ Otp.NET 源码移植 TOTP(thirdparty/Otp.NET,不引包) |
| 密码哈希 | **PBKDF2 原生实现**(不引包,依赖最小化) |
| 缓存 | Redis(StackExchange.Redis) |
| 数据库 | PostgreSQL |
| 日志/DI | ILogger / 原生 IServiceCollection |

**依赖最小化原则(定案)**:第三方 NuGet 包**仅保留 3 个**——SqlSugarCore、StackExchange.Redis、JwtBearer;Otp.NET 与 YitIdHelper 已源码移植;新包引入必须说明理由。
